# مسار ترقية الكشف المحلي — بعد B2

التاريخ: 2026-10-27  
الفرع: `feat/camera-rea-clock`  
القرار الحالي: الخيار أ — `google_mlkit_object_detection 0.14.0`

## الوضع المثبت
- الكشف بالصناديق يعتمد نموذج ML Kit الأساسي المدمج في المكتبة.
- الاسم يُؤخذ من المصنّف الحالي على قصّ كل صندوق، وما لا يُسمّى بثقة يُقال «شيء غير معروف».
- الموضع ثلاثي فقط: يسار / وسط / يمين. بلا أمتار.
- لا تغيير في Gradle، ولا `noCompress`، ولا محرك أصلي إضافي لكل معمارية.

## الخيار ب — مسار ترقية لاحق
EfficientDet-Lite0 عبر `tflite_flutter` يُفعَّل فقط بعد:
1. اجتياز اختبارات الهاتف للخيار أ (المشهد المنزلي، جملة الحالة، وضع المسح).
2. موافقة منفصلة على تغيير Gradle (`noCompress` لملف النموذج) وعلى إضافة المحرك الأصلي لكل معمارية.

لا يُعامل هذا الملف على أنه تفعيل للخيار ب. هو سجل قرار فقط.

## سيناريو اختبار الهاتف للخيار أ
الفئات المعتمدة للمشهد المنزلي:
كرسي، طاولة، كوب، تلفاز، شخص، زجاجة، كتاب، حقيبة.

«باب» ليست فئة COCO، ولا تُستخدم كمعيار نجاح لهذا السيناريو.
